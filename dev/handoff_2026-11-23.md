## How to run

- Server: `node server/server.ts` (set `CREATE_ROOM_LIMIT=100000` for harnesses), UI: `npm run ui`
  (Vite :5173). The e2e and smokes expect :8080 / :5173 unless `WP_SERVER` / `WP_VITE` are set; a Vite
  on another port needs `VITE_SERVER_HOST=<WP_SERVER>`.
- `node dev/extension_e2e.mjs` runs extension then bookmarklet mode (`extension` or `bookmarklet`
  as the first argument runs one). Run it alone: it uses one fixed browser profile, and other browser
  harnesses on the machine make single steps flaky.
- CI runs `npm run build` (vite build + both typechecks).
- Browser harnesses: one fixed `--user-data-dir` per script, wiped at launch; never a fresh temp
  profile per run (that filled 10–35 GB before).
